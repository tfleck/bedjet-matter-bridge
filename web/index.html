❓ Troubleshooting

                

                    Button doesn't appear
                    
Use Chrome, Edge, or Opera. Firefox and Safari don't support Web Serial.

                

                

                    Cannot find serial port
                    
Ensure USB cable supports data transfer. Install CP210x or CH340 drivers if needed.

                

                

                    No pairing code appears
                    
Wait 30-60 seconds after connecting, or press RESET on the board to restart the boot sequence. A code is only printed while a commissioning window is open - an already-paired bridge shows none.
